# Isaac McCorry Portfolio — v3

An editorial exploration of Isaac's portfolio based on the approved concept image. Static HTML with inline CSS and minimal JavaScript; no build or package installation required.

## Preview

Open `index.html` locally, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Content notes

- Project Overworld details and education/work history are based on the v1 résumé.
- Prooflane is described as an active build based on Isaac's stated mission and progress. The page does not claim a released product or validated results.
- The original résumé file is included as a download. Confirm contact details and disclosure preferences before wider distribution.
- The v1 link points to the preserved public snapshot; v3 is separate.

## Design

The composition follows the supplied editorial concept: charcoal, ivory, a restrained warm accent, oversized name, two abstract project panels, four-step process, and concise background. SVG artwork is original code. Motion is limited to small reveal transitions and disabled under reduced-motion preferences.
