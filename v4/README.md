# Isaac McCorry — Portfolio v4

[Live v4](https://ice5-dev.github.io/Isaac-Mccorry-Portfolio/v4/)

Combines v2's original portrait and espresso, ivory, and burnt-orange palette with v3's editorial layout, project artwork, and Prooflane / Project Overworld descriptions.

## Files

- `index.html`: content and semantic structure
- `styles.css`: responsive layout and visual system
- `script.js`: mobile navigation and progressive reveal enhancement
- `isaac-mccorry-portrait.jpg`: unchanged portrait from v2
- `Isaac_Mccorry_Resume.docx`: existing approved résumé

No build step or package dependencies. Open index.html, or serve this folder with any static server. Google Fonts is optional; local font fallbacks remain available. Content remains visible without JavaScript, and motion respects reduced-motion preferences.

Project status and descriptions are retained from v3. No new product results are claimed. Previous versions remain available through the footer links.
